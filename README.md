# 國小五年級 數學・自然 互動教具

### 🔗 線上版：https://yxlin1.github.io/elementary-interactive/

目前版本 **v0.4.0**（側欄左上角會顯示；版本號在 [`js/version.js`](js/version.js)）。

給家長在家陪讀用。手機、平板、電腦都可以直接開。

也可以**下載整包資料夾，用瀏覽器打開 `index.html` 離線使用**——不需要架伺服器、不需要網路。

---

## 怎麼開

雙擊 `index.html`（建議用 Chrome 或 Edge）。左側選單挑一個單元，右側就是內容。

整個資料夾要一起複製，不能只複製 `index.html`。

## 每一章有什麼

| 區塊 | 內容 |
|---|---|
| 🧊 / 🎛 **互動教具** | 可拖曳、可調參數的 3D 或 2D 模型。3D 用滑鼠拖曳旋轉、滾輪縮放 |
| 👨‍👧 **家長導引卡** | 「照著問就好」的 5 個問題，每個都附「為什麼要問這個」 |
| 🚧 **常見錯誤** | 課綱備註裡明確點名的迷思概念，附修正說法與課綱依據 |
| ✏️ **練習題** | 每回合 5／10／20 題可選，隨機生成、同回合盡量不重複。答錯會直接寫出正確答案；回合結束有星等、**錯題回顧**（家長可照著再問一次）、本章最佳紀錄與累計題數，全對放彩帶 |
| ⛶ **全螢幕** | 每個教具右上角都有。進去只留<b>畫布和這個教具自己的控制鍵</b>，說明與練習題留在頁面上 |
| ✏️ **練習區** | 側欄的「練習區」或練習題卡上的「⛶ 專心練習」。畫面上<b>只有題目</b>（側欄、教具、說明全部收起、字放大），可以單章練，也可以<b>整冊混合出題</b>；成績和章節頁共用 |

上方紫色框是這一章對應的**課綱學習內容條目原文**。

**題庫有多大**：練習題不是固定的題目清單，而是 **570 種題型樣板**（分布在 39 個教具裡）。
每種樣板每次都會**重抽數字或情境**，所以實際能出的題目遠多於 570 題。
這個數字在**首頁的「題庫有多大」卡片**、**練習區上方**、以及**每一章練習題卡的右上角**（「本章 N 種題型」）都看得到。

桌機上側欄可以收起來（側欄右上角 ◀，左上角 ☰ 叫回來），狀態會記住。練習題的題數選擇與各章紀錄都存在瀏覽器本機（localStorage），不會上傳；換裝置時到練習區最下面的「進度備份」產生**進度碼**，貼到另一台匯入就會合併（最佳成績取高、題數相加）。

## 版本依據

章節目錄依**學校 115 學年度官方課程計畫**建置（2026 年 8 月起適用）：

| 科目 | 五年級 | 說明 |
|---|---|---|
| 數學 | **南一** | 114 學年度為康軒，**115 學年度改為南一** |
| 自然 | **康軒** | 未變動 |
| 社會 | **翰林** | 五上四個單元已建置 |

已確認但尚未建置的科目：**國語 翰林**、**英語 康軒（Wonder World 5）**。

依據：學校上傳至[臺南市課程計畫平台](https://course.tn.edu.tw/)的 `C5-1 領域學習課程(調整)計畫`，
PDF 表頭載明教材版本，單元名稱與各單元的「活動」也逐週列出，本專案的章節即照此建置。

> 💡 台灣的教科書是**各校自行選用**，同一所學校不同科目、不同學年都可能不一樣。
> 想查自己學校用哪一版：學校網站的課程計畫最準；或到 [OneClass 各校教科書版本查詢](https://version.oneclass.com.tw/)（資料通常晚一個學期）。
>
> **版本不同也不必重做**——各版的單元名稱與順序有差異，但對應的**課綱條目相同**。
> [`js/curriculum.js`](js/curriculum.js) 的每個單元可用 `use` 欄位指向既有教具，
> 換版本只要改章節樹的對應，教具本身沿用。

## 課綱條目來源

每一章掛的條目都是**官方課綱 PDF 逐條抽出的原文**，不是二手轉述。

- **數學**：[十二年國教課綱—數學領域（107.06）](https://www.naer.edu.tw/upload/1/16/doc/815/) — 五年級 27 條（N-5-x／S-5-x／R-5-x／D-5-1）
- **自然科學**：[十二年國教課綱—自然科學領域（107.11），教育部主管法規共用系統 GL001823](https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001823) — 第三學習階段 72 條（INa-Ⅲ ～ INg-Ⅲ）
- **社會**：[十二年國教課綱—社會領域（107.10）](https://www.naer.edu.tw/upload/1/16/doc/819/) — 第三學習階段，目前掛載五上用到的 9 條（Ab-Ⅲ／Af-Ⅲ／Bc-Ⅲ／Ca-Ⅲ／Cb-Ⅲ／Cc-Ⅲ）

> ⚠️ 自然領綱與社會領綱都**不分年級、只分學習階段**（五年級屬於第三學習階段 Ⅲ，與六年級共用同一批條目）。所以這兩科的「年級章節」一律來自教科書單元，課綱條目只是對應標註。

## 手機 / 平板 / 桌機

三種尺寸都<b>實測過</b>（不是只寫了 media query）：

| | 手機 375×812 | 平板 768×1024 | 桌機 1440×900 |
|---|---|---|---|
| 3D 畫布 | 303×273（比例 1.11） | 696×470（1.48） | 788×470（1.68） |
| 3D 佔螢幕高 | 34% | 46% | — |
| 天球是否被切 | ✅ 否 | ✅ 否 | ✅ 否 |
| 2D 圖字級（原 13px） | 9.9px（76% 縮放＋可橫向滑動） | 13px | 13px |
| 控制列高度 | 275px | 92px | 102px |
| 側欄 | 抽屜（☰） | 抽屜（☰） | 固定，可收起（◀／☰） |
| 頁面橫向溢出 | ✅ 無 | ✅ 無 | ✅ 無 |

三個關鍵機制：

1. **3D 畫布高度跟著寬度走**（不超過寬度的 0.9 倍）。固定 470px 在手機上會變成瘦長直式，場景左右會被切掉，而且光畫布就吃掉半個螢幕。
2. **相機距離自動算**。每個 3D 章節用 `S.fit(半徑)` 宣告自己的場景範圍，`kit.js` 同時檢查垂直與水平視角取較嚴格者，任何長寬比都不會切到內容。
3. **2D 圖設最小寬度 470px，容器自己橫向捲動**。硬縮到手機寬度會讓 13px 的字只剩 6px，完全看不清；寧可左右滑。頁面本身不會被撐寬。

直式手機另外會顯示「橫著拿手機看更清楚」的提示（橫式自動隱藏）。

## 品質驗證

不是靠眼睛看，是用程式驗算：

- **題庫**：39 個教具 × 4000 次隨機抽題（**156000 題**）——檢查選項索引、選項重複、空選項、答案型別、NaN／undefined、解題步驟齊全；
  純算式題（`a × b ＝ ?` 這類）另外從題目文字重算一次比對答案（5537 題）。目前**零錯誤**。
  腳本在 [`tools/validate-quiz.js`](tools/validate-quiz.js)：`node tools/validate-quiz.js` 重跑；
  `node tools/validate-quiz.js 4000 m5a-u6` 印出某教具每種題型的樣本供人工檢視；
  加 `--emit` 會更新 [`js/quiz-bank.js`](js/quiz-bank.js)，也就是網頁上顯示的題庫數字。
  2026-09 依均一教育平台南一版各單元小節擴充了 11 個題型最少的教具（每個從 3～4 種變成 9～19 種）
- **靜態檢查**：33 支 JS 全部語法有效；`index.html` 掛的 script 檔案都存在；每一章的課綱條目代碼都對得到官方原文；`impl` 旗標與教具註冊表完全一致
- **答案獨立重算**：從題目文字重新算一次再比對，共 **29491 題**全部相符（四則運算那部分直接用 `eval` 對答案）
- **物理／幾何**：光反射掃過全部 153 種滑桿組合，入射角 vs 反射角誤差 < 10⁻⁶ 度；太陽方位角與高度角對照天文公式；月相亮面比例；柱錐體面／邊／頂點數公式
- **互動壓力測試**：每章所有模式 × 所有滑桿推到極值 × 所有按鈕點過一遍，零錯誤
- **全螢幕**：28 章 33 個教具（25 個 2D、8 個 3D）× 手機直式／手機橫式／桌機三種畫面比例，逐一進出全螢幕——
  檢查長寬比有沒有跑掉、有沒有被容器裁掉、是不是真的放大了、離開後尺寸是否回到原值、暫存樣式有沒有殘留，零錯誤

### 更新線上版

改完檔案後：

```bash
git add -A && git commit -m "說明改了什麼" && git push
```

GitHub Pages 會自動重新建置（約 30–60 秒）。
⚠️ 資源檔的 `Cache-Control` 是 10 分鐘，剛推完可能還看到舊版，按 <kbd>Ctrl</kbd>+<kbd>F5</kbd> 強制重載即可。

### 要新增一章教具

1. 在 `js/curriculum.js` 對應章節加上 `impl: true, kind: '3d'`（或 `'2d'`）
2. 在 `chapters/` 新增一個檔案，用 `Kit.register('章節id', { intro, build, parentGuide, pitfalls, quiz })`
3. 在 `index.html` 加一行 `<script src="chapters/檔名.js"></script>`

### 技術說明

全部使用**傳統 script（非 ES module）**，因此 `file://` 直接開啟就能運作。若改成 ES module，瀏覽器的 CORS 政策會擋住本機檔案，必須架伺服器才能用——那就不符合「家長雙擊打開」的需求了。
